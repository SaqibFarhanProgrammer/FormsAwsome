FORMSAWESOME - MVP FOLDER STRUCTURE
====================================

This project uses Next.js 16.3.3 App Router with feature-based application code.

ROOT
----
app/              Next.js routes, pages, layouts, and API route handlers
components/       Shared UI and reusable visual components
config/            Application configuration
core/              Server-side business logic and infrastructure
features/         Feature-owned components, models, schemas, services, and types
lib/              Small cross-feature utilities and shared integrations
models/           Shared Mongoose models
providers/        React context and application providers
public/           Static assets, images, icons, and fonts
redux/            Redux store and feature slices
tests/            Unit and integration tests
types/            Global TypeScript declarations
utils/             Small generic utilities
proxy.ts          Route protection and refresh-token handling

WHERE NEW CODE GOES
-------------------
1. A URL/page belongs in app/.
2. An API handler belongs beside its URL in app/api/.
3. Business rules and database orchestration belong in core/services/.
4. Feature UI belongs in features/<feature>/components/.
5. Feature models, schemas, services, and types stay inside that feature.
6. Reusable visual primitives belong in components/ui/.
7. Cross-feature Redux state belongs in redux/features/.
8. Do not put business logic directly in page.tsx or a UI component.
9. Keep public form access at /f/[slug] and public submission at /api/f/[slug].
10. Keep form slugs stable after creation; saving must never invalidate shared URLs.

MVP FLOW
--------
Auth -> Create form -> Add fields -> Save draft -> Publish
     -> Public URL /f/[slug] -> Submit response
     -> Owner submissions -> Form detail /all-forms/[slug]

QUALITY CHECKS
--------------
pnpm exec tsc --noEmit
pnpm exec eslint <changed-files>
pnpm build

Do not place generated .next/ output, secrets, or node_modules code in this structure.
