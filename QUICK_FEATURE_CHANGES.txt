1. getFormSubmissionsService
   - Ye function service layer mein hai aur form ke submissions fetch karne ke liye use hota hai.
   - Isme check add karna hai: authenticated user ka access, form ownership, and valid formIdOrSlug.
   - Agar user kisi dusre user ke form ki submissions dekhna chahe, to 403 ya 404 return karna chahiye.
   - Time: 5 minutes

2. getFormAnalyticsService
   - Ye function analytics ke liye use hota hai and isme bhi authorization + ownership check required hai.
   - Validate karna hai ki current user sirf apne form ka analytics dekh sakta hai.
   - Invalid date filters / malformed params ko handle karna chahiye.
   - Time: 5 minutes

3. getSubmissionService
   - Ye function single submission detail ke liye use hota hai.
   - Isme bhi ownership verification add karni hai.
   - Response ko label-based detail mapping ke sath return karna chahiye, raw internal field data na dikhana chahiye.
   - Time: 10 minutes

4. Zod validation for auth + form flows
   - Registration, form creation, form update, and public submissions me schema validation missing hai.
   - Zod use karke shared schema files create karni chahiye, ideally under features/*/schemas or core/schemas.
   - Form fields validation: required checks, type checks, option validation, max length, proper slug rules.
   - Ye structure clean and reusable hona chahiye.

5. Replace raw Error.message usage with AppError
   - Jahan bhi Error.message direct use ho raha hai, wahan AppError class se proper custom messages and status codes use karne chahiye.
   - This keeps API responses consistent and avoids leaking internal details.
   - Critical files to review: utils/catchErrorFunction.ts, core/services/*, app/api/*, and any frontend helper that surfaces raw error messages.

6. Extra security and consistency checks
   - Public form access should reject unpublished or archived forms.
   - Cache and Redis access should not leak private form data into public keys.
   - Legacy routes like /api/forms/update and duplicate routes should be migrated or removed after auth checks.

7. Recommended priority order
   - Step 1: Fix authorization inside getFormSubmissionsService, getFormAnalyticsService, and getSubmissionService.
   - Step 2: Add shared Zod schemas and enforce validation.
   - Step 3: Replace raw Error.message with AppError everywhere.
   - Step 4: Review cache/public form exposure and route security.
